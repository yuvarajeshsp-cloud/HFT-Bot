# HFT-Bot

MT5 Expert Advisors for algorithmic trading.

## Versioning

`MQL5/Experts/FibBreakoutEA.mq5` has an `#property version "X.YY"` line at
the top of the file. Every time changes to this EA are pushed to GitHub,
bump the patch number (e.g. `1.00` → `1.01` → `1.02`) as part of that same
commit. Only bump once per push, even if the push contains multiple
logical changes.
